Official MLIR Affine documentation retrieved 2026-11-01: https://mlir.llvm.org/docs/Dialects/Affine/
The dialect distinguishes dimensions/symbols, affine.apply map substitution, and affine expression forms including add, constant multiplication, floor/ceil division and modulo. This implementation interprets only add and constant multiplication, substitutes actual SSA operands, and retains the pre-existing modular integer and pointer-byte uniqueness proof. Nonlinear symbolic multiplication, varying division and modulo remain rejected. Documentation supplies semantics, not measured profitability.

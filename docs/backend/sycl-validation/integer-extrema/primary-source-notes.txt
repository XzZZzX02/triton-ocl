The MLIR GPU enum distinguishes MINSI/MAXSI/MINUI/MAXUI even though integer element types are signless. SYCL minimum/maximum require the comparison template type to match signedness. All participants must execute the group collective uniformly. This extension applies only to top-level eligible integer reducers and does not extend floating NaN/signed-zero reduction contracts. The operation is associative on the existing 32/64-bit integer domains; no new dtype conversion matrix or MFMA support is introduced.

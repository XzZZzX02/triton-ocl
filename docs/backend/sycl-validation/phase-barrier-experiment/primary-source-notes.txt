id=-gpu-eliminate-barriers> -gpu-eliminate-barriers &nbsp; ¶    Erase unnecessary barriers   Barrier elimination pass. If a barrier does not enforce any conflicting
pair of memory effects, including a pair that is enforced by another
barrier, it is unnecessary and can be removed. Adapted from
&ldquo;High-Performance GPU-to-CPU Transpilation and Optimization via High-Level
Parallel Constructs&rdquo; by Moses, Ivanov, Domke, Endo, Doerfert, and Zinenko in
PPoPP 2023 and implementation in Polygeist.   -gpu-kernel-outlining &nbsp; ¶    Outline gpu.launch bodies to kernel functions   Options&nbsp;<a class=headline-hash href=#options-97
The documented pass is adapted from Moses et al., High-Performance GPU-to-CPU Transpilation and Optimization via High-Level Parallel Constructs, PPoPP 2023 / Polygeist. This candidate uses only duplicate same-scope top-level barriers with no intervening memory effect; it does not implement the complete upstream conflict analysis. Source-barrier count is not a profitability proof. A direct final-IR probe confirms 4 -> 3 llvm.amdgcn.s.barrier calls in the small copy, while timing still regresses.
